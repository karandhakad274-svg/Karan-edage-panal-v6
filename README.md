# Karan Edge Panel

Gaming Dashboard + Game Launcher (RAM, CPU, तापमान, बैटरी, Ping).

## APK कैसे बनाएँ
1. GitHub पर नया repo बनाओ और इस फोल्डर की सारी फाइलें अपलोड करो (`.github` फोल्डर समेत)।
2. Repo में **Actions** टैब खोलो → **Build APK** चलने दो।
3. पूरा होने पर रन खोलो → नीचे **Artifacts** से `KaranEdgePanel-apk` डाउनलोड करो।
4. ZIP खोलकर `app-debug.apk` फोन में इंस्टॉल करो।
